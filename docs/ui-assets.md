# 列车 · 界面素材号（官方 imageId）

> 用途：**给列车 UI 挑图时不用再翻素材库**。素材号是编辑器素材库的条目 ID（`100xxx`/`106xxx`），
> 和**模板索引**（`1073741xxx`）是两套数字，别混。
>
> 来源：`D:\moniji\screenshots\` 的素材库截图（用户从游戏里截的）+ 用户 2026-10-07 指定。
> 完整抄录见 `D:\moniji\千星素材号实测表.md` §六。

## 一、列车档位按钮（用户 2026-10-07 指定 ✔）

| 素材号 | 外观 | 用途 |
|---|---|---|
| **100148** | 双上箭头 ⌃⌃ | **加速档**按钮 |
| **100147** | 双下箭头 ⌄⌄ | **减速档**按钮 |

> 用法：动态创建的图片控件**不继承模板图**，必须显式 `c:SetImage(Enum.ImageSource.StaticReference, 100148)`；
> 单色素材还能用 `c.imageColor = Color.FromRGBA(...)` 染色。

## 四、用之前要记住的两条

1. **能否拉伸**：基础形状（100001~100006）拉长不糊 ✔；圆角/九宫格类拉伸会变形 ⇒ 只能用接近原始比例。
2. **单色 vs 彩色**：单色素材可被 `imageColor` 染色 ✔；彩色素材染色会变脏 ✗；**素材组无法染色** ✗。
