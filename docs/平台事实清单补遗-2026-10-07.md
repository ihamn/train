## 1. ★★★ 文本框 `text` 有长度上限（最大的坑）

| 事实 | 依据 |
|---|---|
| 超限时**不报错、只记日志**：`#spike:211: 文本长度超出限制`；`pcall` 不抛 ⇒ 脚本侧 `fails=0` 会骗人 | 引擎日志原文 |
| 实测：串 ~1500 字符 ✓ 能显示；~2485 / ~2683 ✗ 超限 | 真机实测 |
| 对策：**分块**（他们分 3 条行带，每带 9 行 × 16 列 ≈ 300~900 字符 ✓） | 真机验证 |
| 参考：社区工具 `ImageToRichTextConverter` 按 1000 字符分段（本地有 clone：`tools/irt/main.py`） | [工具 README] |

## 2. ★★ 行距是**引擎定死的**：`行距 = 0.90 × 字号`（实测）

* **不可调**：没有行距字段/方法（官方编辑器文档、客户端控件 API 文档、模拟器 schema 三处都没有）。
* **`<size>` 会连行距一起撑大** ⇒ 想放大像素反而把网格撑松 ⇒ 画面变"稀疏横条" ✗
  要放大像素：**只调控件 `fontSize`** ✓
* `localScaleX/Y` 也**没用**（缩放整个控件，字与缝一起缩，比例不变 ⇒ 缝不消失）✗
* ⇒ **精确控制行距只有两条路**：
  1. **一行一个文本框**（行距 = 自己给的 y 差；相对量，不受锚点/中心影响）✓ 本项目列车 HUD 采用
  2. **图片控件做像素**（无字形内边距 ⇒ 严丝合缝）✓ 像素火推荐路线

## 3. 富文本标签**实际可用**（文档没写，但实测有）

* `<color=#RRGGBBAA>` ✓（A=00 表示透明）⇒ 官方文档只写了变量插值 `{1:p4.测试2}`，**没列样式标签，但标签是存在的** ⚠️
* 透明格的两种写法：`<color=#00000000>█</color>` ✓ / **全角空格 `　`(U+3000)** ✓（**半角空格会被裁** ✗）

## 4. 锚点/轴心是**字段**，不是方法 ⚠️（修正先前口径）

* ✓ 可用：`c.anchorMinX = 0`、`anchorMaxX`、`pivotX` …（**字段赋值**）
* ✗ 不存在：`SetAnchorMin / SetAnchorMax / SetPivot`（方法）
* ⇒ 几何真值优先在**编辑器/模板**里定；运行时只改**位置 + 尺寸**（`SetAnchoredPosition` / `SetSizeDelta`）
