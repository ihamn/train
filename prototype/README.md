# 至冬列车 · 网页玩法小样（重写版）

打开 `index.html`，或 `v2/index.html`。两个入口使用同一套代码，无构建步骤、无网络依赖，支持直接打开本地文件。

触屏点按升降档；键盘 ↑/↓ 或 W/S。一按只换一档，不自动连发。Esc 暂停/继续；切到后台自动暂停。结算后可重开。

开始面板可选择“雪原试行”或“无尽远行”。无尽模式每趟到站后可继续下一趟，或结束远行；暂停面板也可提前结束。累计得分、里程、合规距离和完美奖励保留，进度条与顶部时间显示本趟信息。重跑沿用线路编号，重开清空累计成绩。

**没有作为既定事实处理的内容：** 原始资料未给出完整关卡坐标、真实 km/h 标定、限速计分单价、停靠窗口宽度和停靠计分公式。
因此 `game.js` 中的 `ROUTE` 明确是一条试行线路，不是官方关卡复刻；`RULES` 集中保存所有调参值：

- 雪原试行线路 4200 米；限速段共 1840 米（约 44%）。低速平地 / 高速下坡 / 低速缓坡 / 中速上坡 / 站前慢行，准备与转场距离为 360、470、620、370 米，末尾 300 米不限速用于停靠。出站 0–240 米环境为 0、不限速。坡道保持段环境采用 −2.5、+4.5、−3.5；不限速转场在相邻环境值之间连续渐变，限速目标只在正式路段生效。预告提前 180–400 米。无尽路线参数见文末当前实现说明。
- 加速度比例映射到 km/h/s 的倍率 8（净加速度 0.5 对应指针 6°/秒），显示量程 0～120 km/h；当前列车实际最高速度也为 120 km/h。不限速路段没有合规速度区间，但仍受列车最高速度限制；未引入速度阻力项或各档位终速。
- 合规每米 1 分；停车点 ±5 米，中心 200 分，按位置差线性递减；停稳阈值 0.3 km/h。
- 超过停车点 35 米则结束行程、停靠分为 0，仍然结算；不会无限驶出地图。
- 模拟按真实经过的秒数积分，不使用旧版隐藏的两倍时间缩放。

这些是跑通 P0 所需的小样参数，不宣称是原作数值。文档中的特殊限速段指针角速度、各色带非线性速度响应未精确复刻，因资料标有估测且缺少统一速度映射。

## 仪表校准修正（2026-10-11，实际速度上限已由下文更新）

速度色带、指针与顶部速度标记统一读取模型的显示量程和颜色边界（53、85、109 km/h）。移除手写角度导致的边界偏差，速度读数保留一位小数，并根据未取整的实际速度显示“低于限速 / 速度合规 / 超速”。超过 120 km/h 时数字继续增长、提示超出表盘量程；此量程仍不限制物理速度。速度趋势按当前档位与当前路段即时计算，静止和暂停不再显示正在减速。

## 加速度与局长校准（2026-10-11，覆盖前述早期试验参数）

用户明确：8 秒/6 秒对应净加速度大小 0.5；参考局长约 240–300 秒。线性校准采用 `净值 = 档位力 + 环境贡献`、`指针角速度 = 净值 × 12 °/秒`。在自设 120 km/h / 180° 量程下，真实速度变化率为 `净值 × 8 km/h/s`；模型积分速度与距离，场景和指针读取同一状态，不单独加速动画。绿色色带宽 48°、橙黄色带宽 36°，净值 ±0.5 的完整遍历为 8 秒/6 秒。合法速度范围与色带全宽区分：例如绿带 53–85，当前限速目标 53–84。

当前 4200 米路线参考操作耗时约 286.6 秒、所有 1840 米限速路段合规、零过热、停车误差约 2.8 米。仅为可行性与节奏参考，不设置强制时限，不保证不同驾驶策略同样耗时。21 项模型与绘制测试通过；加速度校准后的手机手感待试玩。

## 蓝区代偿（2026-10-11，覆盖统一倍率规则）

用户确认平地 0 档净值 −1 在蓝区仍只偏转约 −6°/秒。蓝区响应倍率现为其他色带的一半：蓝区净值 × 6°/秒、其余色带净值 × 12°/秒。采用正负对称作为本项目规则；不是单独给指针加视觉缓动。速度、距离、计分和场景共享修正后的物理状态；跨蓝/绿边界和停车瞬间按事件分段积分，停靠参考操作使用分段刹车距离。蓝区净值 −1 遍历约 13.25 秒，绿/橙区净值 ±0.5 的 8 秒/6 秒不变。

最新参考操作约 296.6 秒、1840 米限速全合规、零过热、停车误差约 1.5 米，替代前述旧轨迹数字。22 项测试通过。

## 连续坡度与转场陷阱（2026-10-11，当前方案）

不限速只表示没有速度目标，不表示平地或锁档。`environmentAt(position)` 在转场内采用 `t²(3−2t)` 插值；物理净加速度、HUD 和轨道坡度读取同一环境曲线，轨道高度采用该曲线的解析积分。路段交界的环境贡献和坡度连续，限速不会提前施加。末段前 200 米逐渐回到平地，最后 100 米环境保持 0。

前两个保持段改为低速平地、高速下坡，中间 360 米不限速转场由环境 0 渐增至 +4.5。下一段限速提高，也可能需要降档制动：例如转场后部空档净值仍为正，而 −2 档可以减速。其余转场包含下坡转上坡、上坡加深和上坡减缓，保留判断地形的空间，不自动替玩家换档。

25 项测试通过，覆盖坡度/环境连续、转场可加减速、蓝区校准和整局参考输入。参考操作约 299.7 秒、全部 1840 米限速合规、零过热、停靠误差约 0.6 米；这是可行性验证，实际手感仍需试玩。渐变坡度渲染检查见 `../records/prototype/gradient-transition.png`。页面资源版本为 `20261011-11`。

## 列车最高速度（2026-10-11，当前规则）

用户试玩要求实际速度有上限。本项目先采用与表盘一致的 120 km/h；这是当前实现选择，不声称是官方数值。`advanceMotion()` 精确拆分达到最高速度的时刻，余下时间按最高速度积分距离，避免只截断读数但路程继续超额增长。下坡与正档都不能越过最高速度，净加速度为负时正常减速。HUD 达到上限后显示“已达最高速度”；路段合规判定仍独立，120 km/h 在 85–108 的限速段仍为超速。

26 项测试通过，包含触顶距离、不同积分步长一致性、下坡触顶后制动，以及此前的整局合规参考驾驶。当前资源版本为 `20261011-12`。

## 限速段完美通过奖励（2026-10-11）

按用户要求新增每段全程合规奖励，当前试行值为 100 分，独立于正常距离分及停靠分。驶过完整限速段后立即加分并显示 4 秒奖励提示，结算显示完美段数与累计奖励。不限速段不发放此奖励，每段仅结算一次；重开清空记录。

判定使用每个物理子步在路段内的速度端点，跨入口/出口时沿同一运动积分曲线求边界速度，避免入口前或出口后的调速误伤判定。任意一次低于下限或高于上限都会失去该段奖励，边界值本身合规；静止在段内低于下限也不合规。只进入部分路段不能获奖，暂停不会重置记录。常规合规距离分仍独立计算，失去奖励不撤回已经取得的距离分。

29 项测试通过，包括完整通行仅奖一次、短暂越界、边界时刻、部分通行及重开清零；资源版本为 `20261011-14`。

## 站间无尽模式首版（2026-10-11）

`endless.js` 根据线路编号和趟数生成当前站间路线：每趟四段限速，采用“低→中→高→低”或少量“低→高→中→低”的组合，保持/转场长度作有界变化。首版只使用两类组合。普通准备段至少 400 米；强下坡转场至少 600 米，每四趟出现一趟，避免相邻目标的 A→B→A 回绕。后期部分高速保持段采用更深上坡，难度有上限，过渡距离不随趟数持续缩短。最后 300 米用于进站，前 200 米坡度渐变回平地，最后 100 米保持平地并显示停车条。

模型改为每个状态持有当前路线，计分、完美奖励、预告、轨道高度、列车倾角和站台读取同一份路线。到站后结算本趟合规率及用时，继续时累计成绩保留，位置、档位和本趟完美判定记录重新开始；温度及尚未结束的冷却锁定保留。仅保留当前路线，不累计保存过去路段。结束途中只结清已取得的距离分，不凭空发停靠分；驶过停车范围仍可继续，保持既有无失败态。完成趟数指已结算的站间路程，不等同于成功停靠次数。

验证：`node --test tests/*.test.cjs`（仓库根目录）33 项通过。128 组线路/趟数的结构检查覆盖连接连续、挑战密度、可加减速档位、停车区和有界长度；12 组完整参考驾驶均四段完美、零过热、成功停靠，约 247.0–258.7 秒。参考输入仅用于测试，游戏不自动换档。样本验证不等于所有线路都已实玩。两个入口通过模式选择、四次续程、累计 HUD、目标弧框、主动结束、同编号重跑及返回试行模式的 DOM 运行检查；真实手机布局和手感尚需试玩。
