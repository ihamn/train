# 列车玩法小样 v2（手机竖屏）

## 打开
双击 `index.html`，或手机浏览器打开同一文件。

## 设计基准
- **设计分辨率 1280×720（手机 16:9）**，整屏始终完整可见
- 屏幕更宽时等比放大并留边（不裁切、不拉伸）
- 触屏点按为主，PC 键盘同样可用

## 操作
| 操作 | 触屏 | 键盘 |
|---|---|---|
| 升档 | 点右下「▲ 升档」 | ↑ / W |
| 降档 | 点右下「▼ 降档」 | ↓ / S |
| 重开 | 点左上「重来」 | R |

## 核心循环
读限速区间 → 判断升还是降 → **换档（承担轴温代价）** → 稳在区间内 → 持续得分 → 停靠对位。

**没有 game over**：轴温满只是"被迫空档冷却"的惩罚性停顿。

## 参数（全部经可解性校验）
- 7 档，terminal 速度 0/17/33/50/67/83/100 km/h，相邻间隔 16.7
- 每个限速区间都被**相邻两档夹住** ⇒ 一定能靠"两档来回切"维持
- 轴温：换档 +1/4，冷却 0.07/s（每 3.6 秒可持续换一档）
- **时间尺度 2.0**：物理快进 2 倍。不改档位阶梯（会破坏可解性），只压缩时间
- 全程 1500 m ⇒ 实测约 65 秒一局，合规率约 70%

## 无头实测数据（AI 玩家，不是估计）

|---|---|---|---|---|

| **2.0** | **16.0 s** | **65 s** | **70%** | **906** |

## 已知的 UX 陷阱
**0 档没有牵引力** ⇒ 玩家不换档车永远不动。已加三段引导：
1. 开局提示「先点▲升档让车动起来」
2. 停住 >1.6 秒提示「点▲升档起步」
3. 轴温 >80% 提示「轴温偏高，注意冷却」
