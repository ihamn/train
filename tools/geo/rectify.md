# 侧视线条反解 —— 数学推导

## 问题

给定 3/4 透视下的一张列车图，还原它在**纯侧视正交投影**下的线条。

## 原理

**侧视图的定义性质：所有"沿车长方向"的 3D 直线，在图上必须是水平的平行线。**

而在透视图中，这些线**交于一个灭点 V = (vx, vy)**。
⇒ 任务 = 求一个单应 H，把 V 映到水平方向无穷远点。

## 求解

设图的像素坐标为 (x, y)，齐次坐标 p = (x, y, 1)ᵀ，矫正后 p' = H p。

**条件 1：V 映到无穷远**
```
H · V  =  (·, ·, 0)ᵀ      ⇒     第三行 · V = 0
```

**条件 2：竖直直线保持竖直**（列车的高度方向不斜）
```
H 的 (2,1) 元 = 0    ⇒   p' 的 x 不依赖 y
```

**条件 3：归一化**
```
第三行常数项 = 1
```

由条件 1 + 3，第三行形如 `(a, b, 1)` 且 `a·vx + b·vy + 1 = 0`。

取最简单的解 **b = 0**（即灭线固定在 y 方向无穷远，等价于把 V 压到水平轴）：

```
┌ 1   0   0 ┐
│ 0   1   0 │        其中  W = -vx / vy
└ W   0   1 ┘
```

**⇒ 整个矫正只有【一个参数】。**

## 展开式

```
      x                    y
x' = ─────────      y' = ─────────
     W·x + 1              W·x + 1
```

## 各量的几何意义

| 量 | 含义 |
|---|---|
| `vy` | **灭线高度**。侧视图中，距相机等高处的点都落在 y = vy 这条水平线上 |
| `W = -vx/vy` | **透视强度**。W = 0 ⇒ 正交投影；\|W\| 越大透视越强 |
| `W·x + 1 = 0` | 该 x 处的点在矫正后被推到无穷远 |

## 用法

1. 在原图上找出**任意两条沿车长方向的线**（车顶线、窗台线、腰线、底架线）
2. 求它们的交点 → 得到 V = (vx, vy)
3. 代入公式，把图上所有关键点矫正
4. 连接矫正后的点 → **侧视线条**

## 验证方法

矫正后，**所有原来过 V 的线必须变成水平线**（两端 y 坐标相等）。
若不等，说明 V 取错了，或该线不属于车长方向。

## 注意

- 本公式**只解除"车长方向"的透视**，不解除高度方向的透视。
  若相机有明显俯仰（高度方向也收敛），需要第二组参数，公式扩展为
  `H = [[1,0,0],[a,b,1],[W,0,1]]` 形式（自由度为 2）。
- 本图（官方 3/4 后方视角）相机基本水平，高度方向近似平行，
  **单参数版本足够。**

# 修正（重要）—— 前面单参数推导是错的

## 结论：单灭点不足以矫正

单应 H 有 8 个自由度：
```
把 V 映到无穷远   →  1 个约束
竖直保持竖直       →  1 个约束
⇒ 还剩 6 个自由度未定
```
**⇒ 只给一个灭点无唯一解。** 前面那些"推导"都是在给欠定问题硬凑答案，
数值验证全部不通过（过 V 的线矫正后 Δy ≠ 0）。

## 可解的路：交比法

只要图上有 **n ≥ 3 个真实等距**的特征点，就能定出分式线性变换：

```
u(x) = (a·x + b) / (c·x + d)
```

约束 `u(x1)=0, u(x2)=1, u(x3)=2`，取 a=1 归一化 ⇒

```
c = [ (x3-x1) - 2(x2-x1) ] / [ 2(x3-x2) ]
d = (x2-x1) - c·x2
b = -x1
```

**灭点：`x_vp = -d/c`（分母零点，被推到无穷远）**

代码：`tools/geo/rectify.py`

## 实测结果与失败原因

用实机照片上用户框出的 3 个窗户中心 `x = 340, 380, 411`：

```
解出 c = -0.145161, d = 95.161
灭点 x_vp = 655.6
```

**✘ 灭点 655.6 落在列车自身范围内（列车跨 x 70~1519）。**
灭点落在物体内部几何上不可能 ⇒ **标定前提（三窗等距）不成立。**

矫正后 u 范围 −4898 ~ +3906，输出图 37 万像素宽，**完全崩坏**。

## 教训

1. **这类画风（手绘感、装饰繁复）的照片，自动特征提取极不可靠** ——
   试过边缘检测、Otsu、色相分离、连通域、霍夫变换，全部被背景亮雪和
   车身装饰纹路污染。
2. **灭点位置是很好的自检**：若算出的灭点落在物体内部，则标定必错。
3. **要在物体内部做矫正，需要更远的灭点** ⇒ 需要更长基线的特征
   （例如车尾端点和车头端点，而不是车厢上几个窗户）。
